# Kana Systems brand assets

`kana-systems-logo.png` is the unchanged transparent logo from
https://kana.systems/logo.png, retrieved September 8, 2026 for the user's
requested Kana Legal branding. The app renders the original black artwork
in white using CSS on dark surfaces. No AI-generated replacement or screenshot
crop is used. The brand artwork remains owned by Kana Systems.

`kana-wave.jpg` is the unchanged 1920 × 1080 background photograph from
https://kana.systems/wave.jpg, retrieved September 8, 2026 for the user's
requested matching login hero. It is bundled locally (not hotlinked), with
a navy CSS overlay for legibility. It is not an AI-generated image or a
crop of the screenshot, and no ownership or redistribution license is implied.

`dm-sans-latin.woff2` and `dm-sans-latin-ext.woff2` are unchanged Google Fonts
DM Sans v17 variable-font subsets (normal, weights 400–800), retrieved September
9, 2026 from the Google Fonts CSS API for `DM Sans:wght@400..800`. All UI type,
including headings and the wordmark, uses this locally bundled family.
The SIL Open Font License is included in `public/fonts/DM-Sans-OFL.txt` and
ships with the deployed app. Original font sources:

- https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K6z9mXg.woff2
- https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu6-K6z9mXgjU0.woff2
- https://github.com/google/fonts/tree/main/ofl/dmsans

# Security policy

This repository is a public-data hackathon prototype and is not authorized for
CUI, classified information, source-selection information, PII, privileged
material, export-controlled data, or production contract records.

External training services, including Runpod Secure Cloud, are approved only
for the public CUAD dataset, public FAR/DFARS content, synthetic benchmark
contracts, and openly licensed model weights. Do not transfer GovCloud
credentials, private agreements, application uploads, or operational data to
those services. Runpod training artifacts remain untrusted candidates until
their hashes, provenance, offline benchmarks, and human-review release gates
have been verified locally.

Report suspected vulnerabilities privately through the repository's GitHub
Security Advisory interface. If private vulnerability reporting is unavailable,
contact the repository owners through an established private channel. Do not
include secrets, sensitive documents, exploit payloads, or operational system
details in a public issue.

There is no production-support or remediation SLA. Maintainers will assess
reports against the latest code on the default branch.
